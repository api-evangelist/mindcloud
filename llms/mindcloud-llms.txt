# MindCloud

## What is MindCloud

MindCloud is an AI-assisted integration and automation company. It helps teams connect business systems, build workflows between apps, move operational data reliably, and reduce repetitive work across software stacks.

MindCloud has three main product surfaces:

- Full-service integrations: a white-glove service where MindCloud experts design, build, launch, monitor, and maintain production workflows for customers.
- MindCloud platform: a self-serve integration and workflow automation platform where users can connect apps, configure workflows, and automate business processes.
- Cirra: MindCloud's newest and highest-focus product. Cirra is an AI work assistant for knowledge workers that connects to workplace apps, learns how work gets done, and handles repetitive tasks through natural language.

## Public API

- [OpenAPI](https://mindcloud.co/openapi.json): OpenAPI 3.1 document for the MindCloud Public API v2 surface.
- [API catalog](https://mindcloud.co/.well-known/api-catalog): RFC 9727 catalog that points at the OpenAPI document.
- [Protected resource metadata](https://mindcloud.co/.well-known/oauth-protected-resource): RFC 9728 metadata. Named access levels are `read_only`, `run_workflows`, and `full_access`.
- [Authentication](https://mindcloud.co/docs/api/rest/introduction/authentication): How to send a bearer API key, choose its permissions, and how the creator ceiling limits it.
- [Create an API key](https://app.mindcloud.co/user/api-keys): Self-serve key creation in the platform.
- [MCP](https://connect.mindcloud.co/mcp): Model Context Protocol transport for the same public API.
- Live origin: https://connect.mindcloud.co. Send `Authorization: Bearer $MINDCLOUD_API_KEY`.

## MindCloud building blocks

- Full-service workflows: MindCloud experts turn integration requirements into production-ready workflows, including data mapping, testing, launch support, monitoring, and maintenance.
- Self-serve workflow automation: Users can build and manage workflows that connect triggers and actions across business apps.
- App/action network: MindCloud's app wrappers normalize API behavior so automations and AI agents can interact with many different systems through consistent app actions.
- Cirra skills and automations: Cirra can turn successful natural-language work into reusable skills and recurring automations.
